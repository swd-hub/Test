01画面の全体構成

画面は大きく「左側の操作パネル（サイドバー）」と「右側の地図エリア」の2つに分かれています。

図1：アプリ全体のレイアウトと主要エリア
エリア内容
📋 左サイドバー：ファイル読み込み、指数タイプ・バンドの選択、地域プリセット、ピン、GeoJSONレイヤーなどすべての設定を行う場所。
🗺️ 右側の地図エリア：計算・表示した植生指数を地図上に重ねて表示。クリック操作やドラッグで詳細を確認できる。
◀ ヘッダー左上、および地図左端の ◀ ボタンでサイドバーの表示/非表示を切り替え可能。
ヒント：ヘッダー右側の ⛶ ボタン（またはF11）で全画面表示に切り替えられます。作業に集中したいときに便利です。

02TIFFファイルの読み込み

サイドバー最上部「ファイル読み込み」セクションで、解析対象のTIFFファイルを読み込みます。

図2：ファイル読み込みパネルの各部

読み込み方法は3通り

  1. 📄 ファイル選択ボタン：ダイアログから .tif / .tiff ファイルを複数選択して読み込みます。
  2. 📁 フォルダ選択ボタン：フォルダごと選択すると、中のTIFFファイルをまとめて読み込みます（サブフォルダ含む）。
  3. ドラッグ＆ドロップ：エクスプローラー等からTIFFファイルやフォルダを、点線枠の 「📂 ファイル・フォルダをここにドロップ」 エリアに直接ドラッグして読み込みます。
キャッシュについて：一度読み込んだTIFFは IndexedDB（ブラウザ内蔵のデータベース）に自動保存されます。ページを再読み込みしても、ヘッダーの 💾 DB: — バッジに件数が表示され、ファイルを再読込せずに続きから作業できます。

読み込んだファイルの削除

ボタン動作
🗑全削除：メモリとIndexedDBの両方から読み込み済みTIFFをすべて削除します。
💾DB消去（ヘッダーのバッジも同様）：IndexedDBのキャッシュだけを消去し、現在表示中のメモリ上データは保持します。

03ファイル一覧とフィルタ

読み込んだファイルは一覧に表示され、日付や指数の種類でしぼり込むことができます。

図3：フィルタと一覧表示切り替え

📅 日付フィルタ

プルダウンから撮影日を選ぶと、その日付のファイルだけが一覧に表示されます。

📊 指数フィルタ

バンド種別（B04, B08, VVなど）でファイル一覧を絞り込みます。

一覧の表示切り替え

右上の 🙈 非表示 ボタンでファイル一覧の表示／非表示を切り替え、パネルをすっきりさせられます。ファイル数は一覧上部にカウント表示されます。

04日付×指数 自動計算

同じ日付に必要なバンドが揃っていれば、バンドを1つずつ選ばなくても自動で指数計算ができます。

図4：日付×指数 自動計算パネル
  1. 撮影日付のプルダウンから、解析したい日付を選択します。
  2. 指数タイプで NDVI／EVI／SAVI／MSAVI／GNDVI／RVI／RVI(S1)／TrueColor／Agriculture の中から選びます。
  3. 下の情報欄に、その日付で必要なバンドが揃っているか（バンド状況）が自動表示されます。
  4. 🧮 バンド自動選択して計算 ボタンを押すと、対応するバンドが自動でセットされ、そのまま計算・地図表示まで実行されます。
ヒント：複数日付・複数指数をまとめて確認したいときは、この機能を使うと手動でバンドを選ぶ手間を省けます。

05表示設定（手動計算：指数計算モード）

「表示設定」パネルの 📊 指数計算モード タブでは、バンドを自分で選んで植生指数を計算できます。

図5：指数計算モードの入力項目

操作手順

  1. 指数タイプを選択（NDVI / EVI / SAVI / MSAVI / GNDVI / RVI / RVI(S1) / TrueColor / Agriculture）。
  2. 選んだ指数に応じて必要なバンド選択欄（赤・近赤外・青・緑など）が自動的に表示されます。それぞれのプルダウンから該当するTIFFファイルを選択します。
  3. SAVIを選んだ場合のみ、土壌係数 L のスライダー（0〜1、初期値0.5）が表示されるので、必要に応じて調整します。
  4. 🔢 計算 ボタンを押すと、地図上に指数マップが描画されます。
注意：赤バンドと近赤外バンドに同じファイルを選ぶと「⚠️ 指数 = 0 になります」という警告が表示されます。バンドの選び間違いに注意してください。

選べる指数タイプ一覧

NDVI (B08,B04)EVI (B08,B04,B02)SAVI (B08,B04,L) MSAVI (B08,B04)GNDVI (B08,B03)RVI (B08/B04) RVI(S1) 4×VH/(VV+VH)TrueColor (B04,B03,B02)Agriculture (B11,B08,B02)

06そのまま表示モード

🖼️ そのまま表示 タブでは、指数計算をせずTIFFの値をそのまま色に変換して地図に表示します。

図6：そのまま表示モードの入力項目
  1. バンド選択で表示したいTIFFファイルを選びます。
  2. 表示方法を選びます：色付き済みTIFF（RGB合成）／植生指数カラー／グレースケール／ヒートマップ／ブルー／スペクトル。
  3. 🖼️ 表示 ボタンで地図に描画します。
Copernicus Browserなどで既に色付けされたTIFF（3バンド以上のRGB画像）をそのまま確認したい場合や、生の数値分布をカラーマップで見たい場合に使用します。

07植生指数の役割一覧（解説モーダル）

🌿 植生指数の役割一覧 ボタンを押すと、各指数の計算式・値の目安・活用シーンを解説するポップアップが開きます。

図7：植生指数解説モーダルの構成

上部のタブ（NDVI / EVI / SAVI / MSAVI / GNDVI / RVI / RVI(S1) / まとめ）を切り替えて、それぞれの指数の詳しい説明を確認できます。「まとめ」タブでは、出雲・斐川エリアの水田管理を例にした指数の使い分け方も紹介されています。閉じるには右上の ✕、またはモーダル外側をクリックします。

08不透明度・凡例

図8：不透明度スライダーと凡例の位置

🌫 レイヤー透明度

「不透明度」スライダー（10〜100%）で、地図に重ねた指数レイヤーの透け具合を調整できます。背景の地図（OSM／地理院地図）と重ねて見比べたいときに便利です。

🎨 凡例（カラーバー）

地図左下に表示される凡例で、色と指数値の対応を確認できます。指数タイプによって色のスケールが自動的に切り替わります。

09地域プリセット

島根県内のよく使う地域へすばやく地図を移動できるショートカットボタンです。

図9：地域プリセットボタン

クリックすると地図が該当エリアへ自動的にズーム・移動します。

10ヒストグラム表示

地図ツールバーの 📐 自由四角形 で範囲を指定すると、その領域内の指数値ヒストグラムがサイドバーに表示されます。

図10：範囲選択からヒストグラム表示までの流れ
  1. 地図上で自由四角形を描画し、解析したい範囲を選択します。
  2. 選択範囲内の指数値の分布がヒストグラムとしてサイドバー下部に描画されます。
  3. 「全体統計」パネルには、最小値・最大値・中央値・座標系（EPSG）が表示されます。

11ピン機能

地図上の任意の地点に目印（ピン）を立てて、現地確認したい場所や気になる圃場をメモできます。

図11：ピン機能パネルと地図上の表示

追加したピンはサイドバーの一覧にも表示され、個別に削除・確認ができます。ピンがない場合は「ピンなし」と表示されます。

12GeoJSONレイヤー

農地の区画データ（.geojson / .json）を読み込んで、圃場の境界線を地図上に重ねて表示できます。

図12：GeoJSONレイヤーパネルと地図上の表示
  1. 「🗂 クリックまたはドロップ」エリアをクリックしてファイルを選択するか、GeoJSONファイルを直接ドラッグ＆ドロップします。
  2. 読み込んだレイヤーは一覧に表示され、複数レイヤーを重ねて管理できます。
  3. 🗑 レイヤーをすべて削除 で読み込んだレイヤーを一括削除できます。
連携ポイント：GeoJSONで区画（ポリゴン）を表示すると、次の「ほ場 時系列パネル」機能と組み合わせて使えるようになります。

13ほ場 時系列パネル

GeoJSONで表示した圃場ポリゴンを地図上でクリックすると、右側に「ほ場 時系列指数」パネルが開きます。

図13：ほ場 時系列パネルの構成
  1. 地図上の圃場（ポリゴン）をクリックすると、そのほ場の情報と対象ポリゴンの形状が表示されます。
  2. 時系列グラフ（中央値）：読み込んだ全日付の指数の中央値の推移がグラフ表示されます。
  3. RVI(光)時系列グラフ：光学RVIの推移も別グラフで確認できます。
  4. 日付別 指数値テーブル：日付ごとの中央値が一覧表で確認できます。

CSV出力

ボタン内容
📊CSV（形状欄）：対象ポリゴンに関するデータをCSVで書き出します。
📋CSV（テーブル欄）：日付別指数値テーブルをCSVファイルとして保存します。

パネルを閉じるには右上の ✕ をクリックします。
